# Task Management (MERN + AI)

AI-first work management: organisations, teams, projects, work items, backlog, sprints,
dashboards and notifications, with work items created from plain text or voice.

- `client/` — React + Vite frontend. See [client/README.md](client/README.md).
- `server/` — Node.js + Express + MongoDB API (to come). It must match the paths and response
  shapes of the demo API in `client/src/mocks/handlers`.

Rule for all AI features: the AI suggests, Node.js checks and saves, a person approves.
